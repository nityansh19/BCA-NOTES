# BCA NOTES

A responsive landing page for a student-focused BCA notes platform. Visitors can browse the three BCA years and expand each year to select a semester. Subject lists and syllabus content are intentionally left as placeholders until the curriculum is confirmed.

## Stack
- React
- Vite
- CSS
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Current scope
- Responsive landing page
- Year selection (first, second, third year)
- Semester selection (semesters 1–6)
- Placeholder state for syllabus content
- No checkout, authentication, or PDF delivery yet
